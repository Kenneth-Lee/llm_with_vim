# llm_engine的软件结构说明

llm_engine主要就提供一个函数：answer()，没有参数，它从标准输入获得内容，然后打
印输出到标准输出上。

这个过程分成两部分：

* \_parse\_input()，这部分读取用户的输入，读取的时候会实时返回输入回去（过滤临
  时注释），主要用于获得配置（组合Configure）和对话（找到每个角色的表达）。

* 组合输入，提交给LLM，实时输出LLM的输出

\_parse\_input()是个状态机管理的问题，就是根据每行的内容切换当前角色，然后把对
应的内容收集到对应的角色数据上。

组合输入则是个合并输入的内容，在Configure角色的配置上补充系统配合和默认配置等，
自动组合出一个最合适的参数。然后根据这个参数把对话消息发给LLM，然后实时把LLM的
输出按llm自己定义的格式，输出到标准输出上。

## \_parse\_input()状态机实现

\_parse\_input()的核心问题是：“当前的角色是谁”，这决定了我们在上下文中把什么信
息放到什么角色的定义中。它一行行处理，跳过注释，递归头文件，然后把剩余的信息收
集到当前角色上，一直到遇到角色切换的行，再提交到上下文中。
