# @inc原语的设计思路

@inc原语的主要目的允许.llm文件可以包含其他文件作为公共的头文件，以免每个文件都
要写相同的内容。所以我们有三个基本期望：

1. 在主文件中写成@inc了，提交以后这个地方还是@inc，不会被展开。

2. @inc包含的文件被看作无条件插入到所在位置解释，所以如果@inc文件中包含了其他原
   语，那么那些原语就好像定义在主文件中一样，不会做其他解释。

3. 如此类推，如果一个被@inc包含的文件中再出现@inc原语，那么它也是无条件认为被读
   入的文件是被插入到所在的位置。最终所有这些文件的行会形成一个顺序的序列

为了做到这一点，我们引入一个堆栈形式的数据结构，我们处理主文件的时候，如果遇到
@inc原语，那么主文件的内容和它处理到的行，这些作为状态，可以压栈，然后我们开始
处理被@inc的文件，这个@inc文件被处理完以后，我们从堆栈取出之前的状态，继续处理
前一个文件，直到堆栈中最后一个文件全部被处理完。

为了避免循环依赖导致无限循环，我们引入一个堆栈上限，堆栈深度超过10（这个可以设
置为一个配置参数）以后，我们生成一个表达错误的调试信息，然后跳过这个@inc原语。
