*llm.txt*    LLM Chat Plugin                           *llm-plugin*

==============================================================================
概述                                                          *llm-overview*

LLM Chat Plugin 让你在 Vim 编辑器中与多种 LLM 服务（Ollama、DeepSeek、
Zhipu AI、阿里 DashScope、Haijing、Llama 等）交互。

核心设计：把对话视为可编辑的文本文件（.llm 格式），用户既可以修改问题和
回答来引导对话方向，也能通过快捷键快速提交并生成新内容。

支持两种提交模式：
  - 追加模式（默认）：  保持原有上下文不变，在光标位置追加 LLM 响应
  - 替换模式：          用引擎过滤后的上下文替换缓冲区，从头输出

==============================================================================
文件格式                                                      *llm-format*

.llm 文件的格式：>

    Configure: {'engine_type': 'ollama', 'model': 'qwen2.5:0.5b'}
    System: 你是乐于助人的助手。
    @// 注释内容以 @// 开头
    @## 长久注释以 @## 开头
    User: 你的问题
    Assistant: LLM 的回复
    User: 后续问题
<

  - Configure:  可选，设置引擎参数（JSON/Python 字典格式）
  - System:     可选，对话系统提示
  - User:       用户输入（必须）
  - Assistant:  LLM 生成的回答（自动产生）
  - @//         临时注释（生成时忽略）
  - @##         长久注释（生成时保留）
  - $$path$$    图片引用语法，支持 PNG/JPG/GIF/WebP

==============================================================================
快捷键                                                      *llm-keymaps*

以下快捷键仅对 .llm 文件生效（自动 FileType 触发）。

== Normal 模式 ==

| 按键  | 功能                                                    |
|-------|---------------------------------------------------------|
| <F1>  | 追加模式：提交上下文给 LLM，在光标位置插入响应           |
| <F2>  | 打开/关闭大纲视图，列出所有 User 提问供导航              |
| <F3>  | 预览图片（光标需在 $$path$$ 位置）                      |
| <F5>  | 替换模式：用引擎过滤后的上下文替换缓冲区，从头输出       |
| K     | 中断正在进行的 LLM 请求                                  |
| j     | gj 映射（按显示行移动）                                  |
| k     | gk 映射（按显示行移动）                                  |

== Insert 模式 ==

| 按键  | 功能                                                    |
|-------|---------------------------------------------------------|
| jj    | （快速按 j）追加模式提交                                  |
| JJ    | （快速按大写 J）替换模式提交                             |
| <F1>  | 追加模式提交                                              |
| <F5>  | 替换模式提交                                              |

所有 Insert 模式快捷键会先保存撤销历史（<C-G>u），退出 Insert 模式
调用提交，提交完成后自动恢复 Insert 模式。

== 缩写（abbreviation）==

在 .llm 文件中输入以下缩写可快速插入配置模板：

| 缩写      | 展开内容                                       |
|-----------|------------------------------------------------|
| configO   | Ollama 配置模板                                |
| configAli | 阿里 DashScope 配置模板（含 auth）              |
| configHj  | Haijing 配置模板（含 auth）                    |
| configZp  | Zhipu AI 配置模板（含 auth）                   |
| imgPath   | 图片引用语法 $$path/to/image.png$$             |
| allTools  | 工具列表配置                                   |

==============================================================================
两种提交模式对比                                            *llm-modes*

== 追加模式（默认）== *llm-mode-append*

绑定：<F1> / jj（Insert 模式）

行为：
  1. 收集文件第 1 行到光标行的内容
  2. 传给 llm_engine（不重新输出过滤后的上下文）
  3. LLM 响应从光标下一行开始流式写入
  4. 响应完成后追加 "User: " 提示

特点：
  - 速度快（引擎不需要重写上下文到缓冲区）
  - 保留完整的编辑历史
  - 适合连续追问、长对话
  - 引擎的调试信息（@//）不输出到缓冲区

== 替换模式（旧行为）== *llm-mode-replace*

绑定：<F5> / JJ（Insert 模式，大写 J 快速两下）

行为：
  1. 收集文件第 1 行到光标行的内容
  2. 清除缓冲区中这部分内容
  3. 传给 llm_engine，引擎输出过滤后的上下文 + "Assistant: " + 流式响应
  4. 整个内容写入缓冲区，最后追加 "User: " 提示

特点：
  - 引擎会过滤掉 @// 临时注释、修复图片引用路径等
  - 适合需要整理/清理上下文的场合
  - 上下文很长时会有额外等待（引擎先重写上下文再输出响应）

==============================================================================
配置                                                          *llm-config*

配置文件层次（优先级从高到低）：
  1. .llm 文件中的 Configure: 行
  2. 用户配置 ~/.config/llm_engine/llm_engine.json
  3. 包内置默认配置 default_config.json

支持的引擎：ollama, deepseek, zhipu, ali, haijing, llama 以及
OpenAI 兼容引擎（通过 server_addr 指定）。

常用配置项：>
    {'engine_type': 'ollama',
     'model': 'qwen2.5:0.5b',
     'temperature': 0.8,
     'max_tokens': 4096}
<

==============================================================================
命令                                                          *llm-commands*

:DoGen             追加模式提交（等价于 <F1>）
:DoGenReplace      替换模式提交（等价于 <F5>）
:OpenDiaglogOutline    打开大纲（等价于 <F2>）
:PreviewImage      预览当前行的图片（等价于 <F3>）

==============================================================================
安装                                                      *llm-install*

将 plugin/llm.vim 和 doc/llm.txt 放入 Vim 插件目录：>

    cp plugin/llm.vim ~/.vim/plugin/
    cp doc/llm.txt ~/.vim/doc/
    helptags ~/.vim/doc/
<

或使用任意插件管理器（vim-plug, packer.nvim 等）。

==============================================================================
故障排除                                                  *llm-troubleshoot*

LLM 请求不响应
    - 确认 llm_engine 已安装: pip install -e /path/to/llm_with_vim
    - 确认后端服务（如 Ollama）正在运行
    - 按 K 中断后重试

替换模式长时间无输出
    - 追加模式（<F1>/jj）通常更快，建议优先使用
    - 确认 Configure 中的 engine_type 和 auth 正确

图片无法显示
    - 使用 $$相对路径/图片.png$$ 格式
    - 路径基于 .llm 文件所在目录
